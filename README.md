# OficiosYA Backend

Este repositorio contiene el backend de la aplicación **OficiosYA**.

OficiosYA es una plataforma diseñada para conectar profesionales de distintos oficios con personas que requieren sus servicios. El backend gestiona la autenticación de usuarios, la administración de perfiles, la publicación de servicios y la gestión de solicitudes.

## Características principales

- Registro y autenticación de usuarios
- Gestión de perfiles de profesionales y clientes
- Publicación y búsqueda de servicios
- Solicitud y administración de trabajos

## Tecnologías utilizadas

- Node.js
- Express
- Base de datos: MySQL.
- JWT para autenticación.

## Instalación

1. Clona el repositorio:
   ```sh
   git clone https://github.com/tuusuario/OficiosYABackend.git
   ```
2. Instala las dependencias:
   ```sh
   npm install
   ```
3. Configura las variables de entorno según el archivo `.env`.
4. Inicia el servidor:
   ```sh
   npm start
   ```
